# RUNTIME dependencies of the INE Callejero Source.
#
# Deliberately empty: the package only reads local files (standard library) — there is no
# API for this dataset, so there is not even an HTTP client to install. This is checked
# automatically by tests/test_dependencies.py, which walks the AST of every module and
# fails if any import outside the stdlib appears.
#
# Consequence for the container: the image does not need to install any third-party package.
#
# If a runtime dependency is ever needed, it goes HERE and also in [project.dependencies]
# in pyproject.toml. The two must not diverge.
