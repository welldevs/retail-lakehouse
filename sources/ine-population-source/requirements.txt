# RUNTIME dependencies of the INE Population Source.
#
# Deliberately empty: the package uses only the Python 3.12 standard library (the INE's
# Tempus3 API is plain JSON over HTTPS, with no need for a third-party client).
# This is checked automatically by tests/test_dependencies.py, which walks the AST of
# every module and fails if any import outside the stdlib appears.
#
# Consequence for the container: the image does not need to install any third-party package.
#
# If a runtime dependency is ever needed, it goes HERE and also in
# [project.dependencies] in pyproject.toml. The two must not diverge.
