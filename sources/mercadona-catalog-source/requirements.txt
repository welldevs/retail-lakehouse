# RUNTIME dependencies of the Mercadona Catalog API Source.
#
# Deliberately empty: the package uses only the Python 3.12 standard library.
# This is checked automatically by tests/test_dependencies.py, which walks the AST
# of every module and fails if any import outside the stdlib appears.
#
# Consequence for the container: the image does not need to install any third-party package.
# python:3.12-slim + the code is enough. See README.md, section "Container".
#
# Verification:
#   python -m unittest tests.test_dependencies
#   python -c "import importlib.metadata as m; print(m.distribution('mercadona-catalog-source').requires)"
#   -> None
#
# If a runtime dependency is ever needed, it goes HERE and also in
# [project.dependencies] in pyproject.toml. The two must not diverge.
